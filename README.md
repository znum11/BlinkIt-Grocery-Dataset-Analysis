# BlinkIt-Grocery-Dataset-Analysis
BlinkIT Grocery Sales Analysis 📊
📌 Project Overview

This project focuses on analyzing BlinkIT grocery sales data to uncover insights related to sales performance, customer behavior, product categories, and outlet efficiency.
The analysis is presented through an interactive Power BI dashboard designed to support data-driven business decisions.

🎯 Objectives

Analyze overall sales performance and revenue trends
Identify top-performing and underperforming product categories
Understand customer purchasing patterns
Compare outlet performance based on size, location, and type
Provide actionable insights for business optimization

🗂️ Dataset

Source: BlinkIT Grocery Data (Excel)

Format: .xlsx

Key Data Fields Include:

Item Type & Category
Outlet Type, Size & Location
Sales & Revenue Metrics
Customer Ratings

Item Visibility & Weight

🛠️ Tools & Technologies

Microsoft Excel – Data source
Power BI – Data cleaning, modeling & visualization
DAX – Calculated measures and KPIs

📊 Power BI Dashboard Highlights

The dashboard provides:

Total Sales & Average Sales KPIs
Category-wise and Item-wise Sales Analysis
Outlet Performance Comparison
Sales by Outlet Size & Location
Customer Rating Analysis
Interactive filters and slicers for dynamic analysis

📦 BlinkIT-Grocery-Sales-Analysis

🔍 Key Insights

Certain product categories consistently contribute higher revenue
Medium and large outlets outperform smaller outlets in total sales
Outlet location significantly impacts sales performance
Higher customer ratings often correlate with better sales outcomes

🚀 How to Use

Download the repository
Open powerBI5.pbix using Power BI Desktop
Ensure the Excel file path is correctly mapped if prompted
Explore the dashboard using filters and visuals
